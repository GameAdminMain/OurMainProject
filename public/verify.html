Verify a game

Before every round the game server locks in the order of all 75 numbers with a fingerprint (SHA-256). After the round the order is revealed. This page recomputes the fingerprint in your browser.

How is the fingerprint made?

fingerprint = SHA-256( salt + ":" + numbers in call order joined by "," ), for example SHA-256("a1b2…:23,7,61,…"). The fingerprint was shown in the game before any number was called, so the order could not be changed afterwards.
