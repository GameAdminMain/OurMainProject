Database backup

Creates a full copy of the database (every table, function and row) and downloads it as bbpbackup.sql. It reads from the server's DATABASE_URL. Only the main admin can do this; the file contains all player and money data, so keep it private.

Install pg_dump / restore the file 
pg_dump must exist on the data server. On Railway the dependable way is a Dockerfile: save the supplied
Dockerfile.data_server as "Dockerfile" next to data_server.js (set PG_MAJOR to your database version or newer), then redeploy.

Restore into an empty database:
psql "postgresql://USER:PASSWORD@HOST:PORT/DBNAME" -v ON_ERROR_STOP=1 -f bbpbackup.sql
